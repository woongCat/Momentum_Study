## 🎯 8주차 NLP 수업 개요

### 📋 수업 정보
- **수업명**: NLP 기초: 텍스트 분석과 검색 엔진 만들기
- **수업 시간**: 120분 (2시간)
- **대상**: 머신러닝 기초 지식이 있는 학습자
- **준비물**: 노트북, 인터넷 연결, Python 환경

### 🎯 학습 목표
- 텍스트 데이터의 특성 이해
- 자연어 처리(NLP) 기본 개념 학습
- BOW(Bag of Words)와 TF-IDF 이해
- 실제 검색 엔진 구현 및 활용

### 📚 수업 자료
1. **NLP_수업_완성본.ipynb**: 메인 실습 노트북 (이론 + 실습 통합)
2. **NLP_수업_슬라이드.md**: 이론 설명 슬라이드
3. **수업_진행_가이드.md**: 상세한 수업 진행 가이드
4. **songs.csv**: 노래 가사 데이터

- **시각화**: 단어 구름 생성
